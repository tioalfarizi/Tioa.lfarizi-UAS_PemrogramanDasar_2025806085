# Student Management System v3.0


## Deskripsi

Student Management System adalah aplikasi berbasis web yang digunakan untuk mengelola data mahasiswa, jurusan, dan mata kuliah.

Project ini dibuat menggunakan Node.js, Express.js, MySQL, HTML, CSS, dan JavaScript.


## Fitur

- Dashboard Statistik
- CRUD Mahasiswa
- CRUD Jurusan
- CRUD Mata Kuliah
- Search Data Mahasiswa
- Relasi Database MySQL
- Responsive Design
- Dark Mode
- Grafik Statistik


## Teknologi

Frontend:
- HTML
- CSS
- JavaScript


Backend:
- Node.js
- Express.js


Database:
- MySQL


## Database

Nama database:

db_mahasiswa


Tabel:

- mahasiswa
- jurusan
- mata_kuliah
